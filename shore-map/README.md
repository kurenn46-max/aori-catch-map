# 岸から海図（岸釣りマップ v2）

公開URL: https://kurenn46-max.github.io/aori-catch-map/shore-map/

HTMLのダウンロード・プレビューではなく、AndroidのChromeから上のHTTPS URLを直接開く。

## 使い方
1. 上部で小浜湾・舞鶴・白杉・常神・高浜・越前を選ぶ。
2. 地図上の**岸の釣り座**を1回タップする（あとで「岸を指定」で変更可能）。
3. 下部で釣り座からの半径300m・500m（初期値）・1kmを切り替える。
4. 地図上の任意の地点をタップすると、釣り座からの直線距離を表示する。
5. 「写真/地図」は航空写真・標準地図を切替。「深」は国土地理院の沿岸海域土地条件図（平成元年以降 ccm1、昭和63年以前 ccm2）の切替。
6. 「+ 水深記録」で最後にタップした地点に本人が調べた水深を記録。自分の端末（localStorage）だけに保存する。「記録」からCSVバックアップ可。
7. 右側の◎で現在地を取得（スマホで位置情報の許可が必要）。

## 画面・データの設計
- 地図が主役。上部の海域選択と下部の最小限の操作バー以外は地図を表示する。
- 500mは**海岸線から一律の500mバッファではなく、ユーザーがタップした釣り座からの半径**。公式海図レイヤーそのものは表示している地図全体を閲覧でき、保存記録の絞り込みに選択半径を使用する。
- 国土地理院の標準地図を常時ロードし、その上に航空写真を重ねる。写真がない箇所は標準地図が残る。
- 公開沿岸調査図はズーム14～16のタイル。拡大表示しても元の測量精度は高くならない。表示は整備海域に限る。取得枚数は画像が返った件数であり、水深点の有無や精度の保証ではない。
- 海しるAPIは別途サブスクリプションキーが必要。今回のアプリでは秘密情報をGitHub公開ファイルに埋め込まず、APIを無断使用しない。Navionics / new pec の有料または許諾対象データも取り込んでいない。
- J-EGG500は500mメッシュで岸際の小さな根や浅場の調査に不向きなため、実在しない細かい水深数値を生成しない。
- 航空写真の海の色は水深の測定値ではない。
- GPS、潮汐、安全性、立入可否、航海用途を保証するものではない。現地規制と最新の公式海図を確認すること。

## プライバシー・技術上の限界
地図タイルを表示するため、地図プロバイダーに表示エリアのタイル要求が発生する。GPSの取得はユーザーが◎を押した場合だけ。保存した水深記録はこのアプリのページを開いた**同じブラウザ／端末**に保存され、サーバーに同期されない。サイトデータの削除で消えるのでCSVを書き出す。

GitHub Pagesへの配置完了・JavaScriptの構文検査・模擬DOMによる主要操作のチェック済み。実地のAndroidネットワークおよび沿岸タイルの対象エリアについては、現物表示で確認が必要。

元の青りキャッチマップや、失敗した旧 kaizu-map のファイルは変更していない。
